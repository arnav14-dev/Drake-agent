# an executable partly on what it declares about itself: a 21MB unsigned binary with
# NO company, NO product name and NO version looks exactly like the things people
# actually get infected by, and on 2026-08-22 that score plus our keystroke behaviour
# got a build's hash marked malicious in Microsoft's cloud — after which every
# customer's download of that exact file said "virus detected". A version resource
# does not sign the file (only the code-signing certificate truly fixes reputation),
# but it removes the "anonymous binary" penalty and it is what Windows shows a human
# who right-clicks → Properties → Details before deciding to trust it.
